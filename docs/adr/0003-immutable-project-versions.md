# ADR 0003：项目修改采用不可变版本

状态：Accepted

## 背景

Agent 可能在长任务中失败，用户需要比较、预览和恢复修改前的项目。直接覆盖当前目录会造成无法解释的部分状态。

## 决策

每次 Builder 修改都创建候选版本。只有通过 Reviewer 并经用户或系统明确提交后，版本才成为当前版本。预览和部署都绑定版本 ID。

## 原因

- 回滚简单。
- 运行结果可重现。
- Reviewer 的报告可以绑定具体版本。
- 用户不会看到半完成文件。

## 后果

- 需要对象存储和版本清理策略。
- 大项目会产生存储成本。
- 文件编辑器必须明确“编辑会创建新版本”。
