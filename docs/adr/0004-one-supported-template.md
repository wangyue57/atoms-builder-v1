# ADR 0004：一期只支持一个受控 Web 模板

状态：Accepted

## 背景

支持任意框架会让 Builder、Reviewer、预览、部署和错误修复同时变复杂，难以达到可靠性目标。

## 决策

一期只支持 Next.js + TypeScript + Tailwind + Playwright 的 Web 模板。其他框架通过后续模板 Adapter 加入。

## 原因

- 固定启动命令、检查命令和部署方式。
- 可以建立高质量任务集和浏览器测试。
- Builder 的工具权限和受保护文件更简单。
- 可靠性指标可以在同一技术栈上积累。

## 后果

- 初期用户选择少。
- 模板升级需要版本化和迁移策略。
- 不能把“一期成功”宣传为支持任意类型应用。
